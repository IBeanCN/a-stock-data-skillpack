# 通用约定

## 依赖

```bash
pip install -r requirements.txt
```

- `requests`：HTTP 数据源。
- `pandas`：DataFrame 输出和表格解析。
- `lxml`：`pandas.read_html()` 解析 HTML 表格。
- `mootdx`：通达信 TCP 行情、财务快照、F10。
- `stockstats`：技术指标扩展，当前端点不强制使用。
- `numpy`：筹码分布网格计算。
- `baostock`：估值历史、换手率、停牌/ST、上市/退市状态（不支持北交所）。
- `xlrd >= 2.0`：读取申万 `.xls`；`openpyxl`：读取人民银行 `.xlsx`。

环境检查：

```bash
python3 scripts/validate_env.py
```

## Ticker 归一化

`normalize_code()` / `norm_ticker()` 严格解析并支持：

| 输入 | 输出 |
|---|---|
| `688017` | `688017` |
| `SH688017` / `sh688017` | `688017` |
| `688017.SH` / `688017.sh` | `688017` |
| `SZ000001` | `000001` |
| `BJ832000` | `832000` |
| `600519.XSHG` / `000001.XSHE` | `600519` / `000001`（聚宽后缀，上游 #55） |

格式错误、前后缀并用、市场标识与号段矛盾时会抛 `ValueError`，不会提取数字后静默猜测。`600519.XSHE` 这类聚宽后缀与号段矛盾的写法同样会被拦下。个股专用接口使用 `stock_only=True`，可拒绝显式写成 `SH000001` 的沪市指数。

`get_prefix()` 支持显式 `sh`/`sz`/`bj` 前缀和等价 `.SH`/`.SZ`/`.BJ` 后缀；显式市场优先于号段推断。裸代码规则：

| 代码开头 | 前缀 |
|---|---|
| `92` | `bj`（北交所新号段，必须先于 `9` 判断） |
| `5` / `6` / `9` | `sh`（`5` 含沪市 ETF/LOF） |
| `4` / `8` | `bj` |
| `000300` / `000905` / `000016` / `000688` / `000852` / `000010` | `sh`（沪市指数白名单） |
| 其他 | `sz` |

`get_prefix()` 除 `.SH`/`.SZ`/`.BJ` 外也认聚宽 `.XSHG`/`.XSHE` 后缀（`_JQ_SUFFIX` 映射成市场）。

`to_joinquant(code)` 把任意受支持写法转成聚宽代码（`600519.XSHG` / `000001.XSHE`）；北交所没有公开的聚宽后缀，
传北交所代码抛 `ValueError` 不猜。本 Skill 不带回测引擎，取到的数据可以接进聚宽等回测框架。

`000001` 默认是 `sz000001`（平安银行）；如需上证指数须显式传 `sh000001`。`tencent_quote()` 保留显式前缀入参作为结果键，允许同批查询 `sh000001` 与 `sz000001`。

北交所存量股票已大规模迁至 `920xxx`。`43/83/87` 老号段可能返回 HTTP 200 但内容是定格报价或空研报；腾讯结果会标记 `is_stale` / `stale_reason`，东财个股研报遇老号段空结果会抛错，调用前应按名称反查现行代码。

## 数据源优先级

原则（上游 v3.9.0 起）：能用腾讯 / 交易所官方，就别用东财。东财只用于它独有的数据，并且必须经 `em_get()` 串行限流。
同步上游 v3.9.0 / v3.10.0 后是十五层、87 个入口（82 主入口 + 5 备胎）、34 个来源。

| 优先级 | 数据源 | 用途 | 风险 |
|---|---|---|---|
| 1 | 腾讯财经 | 实时价、PE/PB、市值、换手率、涨跌停、指数、ETF、日周月与分钟 K 线、当日逐笔 | 低；K 线单域名约 600 次后返回空，三个入口自动轮换 |
| 2 | 交易所官方 | 上期所 / 上期能源 / 郑商所 / 中金所 / 广期所日行情与期权、上金所现货、沪深 ETF 份额、中证 / 国证指数 | 权威一手；中金所与广期所只能走 HTTP |
| 3 | 通达信官网 | 每日盘后包（全市场日线含成交额） | 不封 IP，约 2.7MB/次 |
| 4 | 通达信 TCP / 巨潮 | 财务快照、F10、公告、互动易 | 2026-09 起行情命令返回空，财务 / F10 用 `check='finance'` |
| 5 | 新浪财经 | 复权因子、财报三表、ETF 期权、研报列表、期货实时与日 K、A50 | 低；研报列表内置 6 秒最小间隔 |
| 6 | 华尔街见闻 / 央视网 | 7×24 快讯、全球宏观日历、新闻联播 | 低 |
| 7 | 中国货币网 / 中债 | 回购定盘利率、收益率曲线 | 低 |
| 8 | 同花顺 / 百度股市通 | 热点、题材归因、北向、热榜、一致预期、带均线日 K | 低，部分接口需 UA |
| 9 | iwencai | NL 语义搜索 | 需 key |
| 专用 | baostock | 历史估值、换手率、停牌/ST、上市/退市 | TCP；不支持北交所 |

## 错误契约（上游 v3.9.0 起统一）

- `ValueError`：参数错误，或来源确认「确实没有数据」（非交易日、代码不存在、区间内无数据）。
- `RuntimeError`：网络 / HTTP / 非 JSON、来源结构或字段变了、翻页不完整、数值或日期认不出、总数与条数不符。
  这类情况**不要**当成「没有数据」；它意味着来源格式可能已变，应当停下并修解析器。
- 来源行缺字段时统一抛带函数名和字段名的 `RuntimeError`，不再漏出 `KeyError`。
- 数值字段拒收布尔值（`float(True)=1.0` 会把格式错误静默写成价格 / 成交量）；来源自报的页数 / 总数只认整数。

新端点返回 DataFrame 时带 `attrs`：`source` / `source_url` / `fetched_at`；引用数据时把来源和日期一并说明。

## 东财防封

`em_get()` 内置：

- session 复用。
- 默认 `trust_env=False`，不继承系统代理。
- 直连失败后可 fallback 到环境代理。
- `EM_MIN_INTERVAL=1.0` 秒最小间隔。
- 0.1-0.5 秒随机抖动。
- 三次直连重试。

批量筛选时把 `EM_MIN_INTERVAL` 调大到 1.5-2 秒。不要并发请求东财接口。

## 输出要求

回答中必须说明：

- 数据源。
- 观察日期、公告日期或报告日期。
- 缺失字段。
- 接口为空、无 key、无机构覆盖、非交易日、源被风控等 caveat。
- 如果包含估值或题材判断，必须区分事实和推断。

不要用训练数据补当前市场价格、资金流、公告、新闻、研报。
