# 宏观层

| 端点 | 数据 | 数据源 |
|---|---|---|
| `pboc_social_financing(year=None)` | 社会融资规模增量（月频） | 人民银行 |
| `nbs_pmi()` | 制造业 / 非制造业 / 综合 PMI（月频） | 国家统计局 |
| `chinabond_yield_curve(start, end=None, curve="all")` | 国债 / 商业银行 AAA / 中短票 AAA 收益率曲线 | 中债（中央结算公司） |
| `repo_fixing_rates(kind="FR")` | 银行间回购定盘利率 FR / FDR | 中国货币网 |
| `lpr_history()` | LPR 贷款市场报价利率全历史 | 东财 |
| `macro_calendar(start, end=None, country=None, min_importance=1)` | 全球宏观日历（公布值 / 预期 / 前值 + 事件） | 华尔街见闻 |

## 人民银行社会融资规模

`pboc_social_financing(year=None)` 从人民银行统计索引进入年份页、社会融资规模专题页，再读取 XLS/XLSX。返回月度 12 列：社融增量、人民币/外币贷款、委托/信托贷款、未贴现承兑、企业/政府债券、股票融资、存款类 ABS 和贷款核销。

仅支持 2021 年起的新表格式；逐单元格解析月份、只保留目标年，并删除尚未发布且 `afre_total` 为空的月份。

## 国家统计局 PMI

`nbs_pmi()` 从国家统计局最新发布页定位采购经理指数，返回制造业、非制造业商务活动、综合产出 PMI，以及大/中/小型企业 PMI。解析会移除普通空格、全角空格和 NBSP，并兼容企业分档的三种常见措辞。三个主 PMI 任一缺失都会抛错并附来源 URL。

## 中债收益率曲线（上游 v3.9.0 §11.3）

- `curve`：`all` / `treasury`（国债）/ `bank_aaa` / `mtn_aaa`；期限 3 月到 30 年共 8 档，收益率单位 %。
- 中短期票据曲线没有 30 年，该列为 None。
- 官网单次查询超过 1 年**静默返回 0 行**，函数按 360 天切片。
- 各曲线起点：国债 2006-03-01、中短期票据 2006-12-25、商业银行 2009-12-24；`start` 早于起点时从起点开始取。
- `all` 模式下 2006-03-01 起每天 1 条（国债）、2006-12-25 起 2 条、2009-12-24 起 3 条；返回的每一天都按这个规则核对曲线是否齐全，缺一条抛 `RuntimeError`。
- 中债不公布债券市场交易日历、页面也没有总条数，整天缺失无法判定；只有整段切片 7 天以上 0 行才报错。需要严格逐日核对请自备交易日历比对 `date` 列。

## 回购定盘利率（上游 v3.9.0 §11.4）

- `kind='FR'`：全市场 `FR001/FR007/FR014`（约近 3 年，实测 748 行）；`kind='FDR'`：银银间 `FDR001/FDR007/FDR014`（约近 1 年，实测 249 行）。单位 %。
- 三个期限都是必填，整行为空时列数照样对得上，原来会返回利率全为空的行，现在报错。

## LPR 全历史（上游 v3.9.0 §11.5）

- 2013-10 至 2019-08 是旧机制的逐日 1 年期 LPR（`lpr_5y` 为 None，5 年期品种 2019-08-20 才设立）；2019-08 改革后每月 20 日报价。
- 东财同一报表里混着旧贷款基准利率调整行（实测 38 行，最晚 2015-10-24），LPR 字段为空，已剔除；不为空却认不出的值会报错，不返回空的 `lpr_1y`。

## 全球宏观日历（上游 v3.9.0 §11.6）

- `start/end` 是北京时间、含两端，区间最多 92 天；接口单次只允许一周，函数按 7 天切片。
- `country` 例 `'中国'` / `'美国'`；`importance` 1–4（数字越大越重要，4 = 工业增加值、社零这类头条数据），`min_importance` 按它过滤，只收 1–4。
- 满 7 天且已开始的窗口 0 条抛 `RuntimeError`（实测过去任一周都有 150 条以上）；单日、周末或三周以后的日期可能确实为空；整个区间都没有条目抛 `ValueError`。
- 筛完为空（`country` 写错或门槛过高）也抛 `ValueError`，不返回空表；来源的 `importance` 必须是 1–4 的整数，`true` / `99` / `"2"` 都会报错。

## 使用边界

社融与 PMI 为月频、LPR 为月频（旧机制逐日）、中债曲线为日频、回购定盘为日频，不能互相伪装成交易信号。
调用结果必须标注统计期 / 日期和来源 URL；页面结构变化时应停止并修复解析器，不要用训练数据补值。
